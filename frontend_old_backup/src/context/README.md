# THƯ MỤC: src/context/
MỤC ĐÍCH:
- Quản lý trạng thái toàn cục (Global State) của ứng dụng bằng React Context API.
- Lưu trữ dữ liệu cần dùng xuyên suốt ở nhiều trang mà không muốn truyền qua nhiều cấp props.
VÍ DỤ:
- AuthContext.jsx (lưu thông tin user hiện tại, trạng thái login, token)
- ThemeContext.jsx (quản lý giao diện sáng/tối)
